# SiamFC++ Google Colab Starter

本專案提供：
- `SiamFCpp_Colab_Test.ipynb`：環境檢查、原始碼下載、README/入口檢查、權重與設定檔檢查的 Notebook。
- `README.md`：使用方式與已知限制。

## 使用方式
1. 將 `SiamFCpp_Colab_Test.ipynb` 上傳至 Google Drive，或在 Colab 使用「檔案 → 上傳筆記本」。
2. 在 Colab 選擇 GPU 執行階段。
3. 由上而下執行每一節。
4. 依下載到的倉庫版本 README 安裝依賴、取得官方權重及設定檔，並使用該版本支援的測試參數。

參考文章：
https://blog.csdn.net/qq_30347421/article/details/104534297

預設原始碼網址：
https://github.com/MegviiDetection/video_analyst

## 重要限制
這是可重現的測試環境骨架，不是已完成端到端驗證的二進位發行版。原始碼、依賴、權重和測試參數可能隨版本改變；請以實際倉庫 README 為準。此工作環境無法連線 GitHub，因此沒有在此完成下載、安裝或 GPU 追蹤測試。
